# 求人サイトナビ

新卒・中途の求人サイトについて、運営会社と資本関係、企業が払う料金の仕組み（成果報酬・掲載課金など）、掲載情報、ニュースをまとめた案内サイトです。採用コストの試算もできます。

## ファイル

- `index.html`：ページ本体
- `sites.json`：各サービスの基本情報と、最近の主な変化
- `plans.json`：料金モデルと料金の内訳、試算に使う金額（毎週確認）
- `companies.json`：運営会社とグループの情報（毎週確認）
- `news.json`：サービス別・業界と制度の動きのニュース（毎週更新）

内容は公開されている公式発表・報道・代理店資料をもとにまとめたもので、正確さを保証するものではありません。利用前に各社の公式情報を確認してください。
