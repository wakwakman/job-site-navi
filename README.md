# 求人サイトナビ

新卒・中途の求人サイトについて、運営会社と資本関係、企業が払う料金の仕組み（成果報酬・掲載課金など）、掲載企業の特徴と営業仮説、業界構造、ニュースをまとめた営業向けの業界構造辞書です。企業の特徴から関連しそうな求人媒体を逆引きでき、採用コストの試算もできます。

## ファイル

- `index.html`：ページ本体
- `sites.json`：各サービスの基本情報と、最近の主な変化
- `plans.json`：料金モデルと料金の内訳、試算に使う金額（毎週確認）
- `companies.json`：運営会社とグループの情報（毎週確認）
- `news.json`：サービス別・業界と制度の動きのニュース（毎週更新）
- `insights.json`：媒体ごとの掲載企業の特徴（推定）、利用理由、営業仮説、確認ポイント
- `business_models.json`：8つのビジネスモデルの仕組み・お金の流れ・読み取れること、グループの分析
- `sales_guides.json`：営業仮説の考え方（8テーマ）

`insights.json`・`business_models.json`・`sales_guides.json` は、サービスID（`sites.json` の `id`）で既存データと結びついています。運営会社・料金・ニュースは既存のファイルだけを正とし、二重に持ちません。

## 情報の区分

- ①確認済み：公式サイト・公式IR・公的資料・大手報道で確認できた内容
- ②第三者：代理店資料・業界メディア・調査記事など
- ③独自の仮説：媒体の特徴や料金モデルから考えた推定。事実ではありません

内容は公開されている公式発表・報道・代理店資料をもとにまとめたもので、正確さを保証するものではありません。利用前に各社の公式情報を確認してください。
